## Prerequisites

- [ByteSend API key](https://bytesend.cloud/dev-settings/api-keys)
- [Verified domain](https://bytesend.cloud/domains)

## Installation

Install the ByteSend Go SDK:
```bash
go get github.com/NodeByteHosting/bytesend-go
```

## Initialize

Create a new client using your API key.
```go
package main

import (
    "context"
    "log"

    bytesend "github.com/NodeByteHosting/bytesend-go"
)

func main() {
    client, err := bytesend.NewClient("bs_12345")
    if err != nil {
        log.Fatal(err)
    }
}
```

API keys can also be supplied via the `BYTESEND_API_KEY` environment variable.

### Self-Hosted Setup

If you are running a self-hosted version of ByteSend, provide the base URL using `WithBaseURL`.
```go
client, err := bytesend.NewClient(
    "bs_12345",
    bytesend.WithBaseURL("https://bytesend.cloud"),
)
if err != nil {
    log.Fatal(err)
}
```

<Info>
The base URL should be the root domain only. Do not include `/api/v1`, as the SDK manages API paths internally.
</Info>

### Options

- `WithBaseURL(url string)`: Override the base API URL (e.g. for self-hosting)
- `WithHTTPClient(*http.Client)`: Provide a custom HTTP client

<Info>
The default HTTP client uses a 30s timeout. Requests include a `User-Agent: bytesend-go` header.
</Info>

## Sending Emails
```go
resp, errResp, err := client.Emails.Send(
    context.Background(),
    bytesend.SendEmailPayload{
        To:      []string{"hello@acme.com"},
        From:    "hello@company.com",
        Subject: "ByteSend email",
        HTML:    "<p>ByteSend is the best way to send emails</p>",
        Text:    "ByteSend is the best way to send emails",
        Headers: map[string]string{
            "X-Campaign": "welcome",
        },
    },
)

if err != nil {
    log.Fatal(err)
}

if errResp != nil {
    log.Fatalf("API error: %s", errResp.Message)
}

log.Printf("Email queued with ID: %s", resp.EmailID)
```

<Info>
Custom headers are forwarded as-is. ByteSend only manages the `X-ByteSend-Email-ID` and `References` headers.
</Info>

## Managing Contacts

### Get Contact Book ID

Retrieve the contact book ID from the ByteSend dashboard.

### Create Contacts
```go
contact, apiErr, err := client.Contacts.Create(
    context.Background(),
    "contactBook_123",
    bytesend.CreateContactPayload{
        Email:     "hey@bobdole.com",
        FirstName: "Bob",
        LastName:  "Dole",
    },
)

if err != nil {
    log.Fatal(err) // transport error
}

if apiErr != nil {
    log.Fatalf("API error: %s", apiErr.Message)
}

log.Printf("Contact ID: %s", contact.ContactID)
```

### Update Contacts
```go
contact, apiErr, err := client.Contacts.Update(
    context.Background(),
    "contactBook_123",
    "contact_456",
    bytesend.UpdateContactPayload{
        FirstName: "Bob",
        LastName:  "Dold",
    },
)

if err != nil {
    log.Fatal(err)
}

if apiErr != nil {
    log.Fatalf("API error: %s", apiErr.Message)
}
```
